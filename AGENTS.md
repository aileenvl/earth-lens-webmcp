# Earth Lens agent instructions

Read `CONSTRAINTS.md` before writing code. Do not weaken it to make a change pass.

ArcGIS Maps SDK for JavaScript is the accepted geospatial engine. Do not replace
it without explicit approval and a superseding architecture decision record.

Implement only work selected from the accepted capability map, module specs,
and `tasks/todo.md`. Keep changes small, test them, and preserve provenance and
human confirmation boundaries.
